# Personal website

Static portfolio for [dheerajnamburu.com](https://dheerajnamburu.com/), published by GitHub Pages from the root of `main`.

The first screen prioritizes Microsoft experience, AI delivery impact, work bullets, independent products, and contact links. Additional engineering detail, full app images, earlier experience, and technical skills follow.

## Local preview

Run `python3 -m http.server 4198 --bind 127.0.0.1` from this directory.

## Analytics

Google Analytics property: `558444854`. Web measurement ID: `G-P2LV2GRM83`. [Open the dashboard](https://analytics.google.com/analytics/web/#/a407854991p558444854/reports/intelligenthome).

Tracking starts only after visitors allow analytics. Advertising features are disabled. The footer lets visitors change their choice. Localhost does not send analytics.

Custom events: `contact_email_click`, `resume_download`, `project_visit`, `social_profile_click`, `reading_depth`, and `engaged_reading`. Google Analytics adds traffic sources, device information, approximate region, and engagement reports. These data do not identify anonymous visitors by name.

## Assets and dependencies

Bootstrap 5.3.8 is vendored with its MIT license. DM Sans and Instrument Serif are self hosted with their OFL licenses. Product previews show actual app screens: CommandGate in demo state, Fouro's public guest interface, and FilmyCam's App Store imagery. Full resolution versions are retained for the gallery.

## Publishing

Verify layout, local asset links, consent behavior, and JavaScript syntax before pushing to `main`. Wait for the GitHub Pages build to finish, then check the live HTML, stylesheet, image assets, resume, and analytics event delivery.
