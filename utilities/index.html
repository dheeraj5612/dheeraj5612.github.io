HOW THEY ARE BUILT

Small sites on shared tooling.

Small and static.

46 are static builds, 2 are Next.js apps, and 2 are Node API apps. 48 of the 50 have no npm dependencies. All of them run on Cloudflare.

One shared data service.

One shared Cloudflare Worker serves public data from sources like FRED, SEC EDGAR, FINRA, and NYC Open Data to the sites that need it, with caching, timeouts, and a last good fallback.

Repeatable releases.

Live sites are released from pinned commits, with a receipt recorded for each one. A launch controller checks preview builds before they go out, and previews stay out of search engines.

Analytics only with consent.

Every site asks before measuring anything, and sends no analytics request until the visitor agrees.
